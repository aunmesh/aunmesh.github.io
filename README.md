# aunmesh.github.io
Minimal academic homepage for Asim Unmesh (GitHub Pages).

## Quick Start
1. **Create the repo** named `aunmesh.github.io` on your GitHub account.
2. **Push these files**:
   ```bash
   git init
   git branch -M main
   git add .
   git commit -m "Initial minimal homepage"
   git remote add origin git@github.com:aunmesh/aunmesh.github.io.git
   git push -u origin main
   ```
3. Wait ~1–2 minutes. Your site will be live at `https://aunmesh.github.io/`.

## Customize
- Edit `_config.yml` (title, description, logo).
- Edit `index.md` to add links for Projects, Publications, and CV.

## Notes
- Uses `jekyll-theme-minimal` (built-in to GitHub Pages).
- No extra build steps required.
